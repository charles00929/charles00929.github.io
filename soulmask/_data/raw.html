Soulmask Talents

This document describes character talents.

Console Commands

The following commands can modify the list of talents applied to a character (tribesman or starting character).

Selecting a Character

The AddNg and RemoveNg commands apply to the currently selected character. A character can be selected by targeting them and using the Select command. When using the command, the console will print a message indicating the selected character. You can use the ClearSelect command to deselect a previously selected character. If no character is selected, then the AddNg and RemoveNg commands will affect the controlled character instead.

Examples of selection commands.

gm Select
gm ClearSelect
Adding a talent

AddNG NGId[int] bGood[bool] InLvl[int]

Target: selected character

Adds the specified talent.

  • NGId: The ID of the talent to add.
  • bGood: Specifies whether the talent should be set to good or bad
    • 0: A bad talent that has a chance to be unlearned when leveling.
    • 1: A good talent that will be permanent.
  • InLvl: Specifies the character level that the talent would have been awarded. This has no impact on gameplay - the talent is granted immediately when using this command.

NOTE: Any talent can be set as positive or negative using the bGood parameter. Talents that are set to negative have a chance to be removed automatically when the character reaches certain levels. Whether a talent is set to positive or negative does not affect what the talent actually does.

Following is an example of adding "Swift Pace 3" to the selected character.

gm AddNG 100013 1 0
Removing a talent

RemoveNG NGId[int] bGood[bool]

Target: selected character

Removes the specified talent.

  • NGId: The ID of the talent to remove.
  • bGood: Specifies whether the talent is set to good or bad.
    • 0: The talent is in the "negative" group.
    • 1: The talent is in the "positive" group.
Removing all talents

ClearNG

Target: selected character

Removes all talents.

Following is an example of removing all talents from the selected character.

gm ClearNG
Locating NPCs with a talent

FindSCGLoc NGIndex[int] PinZ[int]

Target: current player (self)

Finds all wild NPCs which have the specified talent and the specified quality or higher and marks them on the current player's map.

  • NGIndex: The ID of the talent to search for.
  • PinZ: The minimum quality NPC to search for.

Example command usage. The following locates all NPCs with the "Swift Pace 3" talent who are at least quality 4.

gm FindSCGLoc 100013 4
